# 脅威モデル

## 守るもの

- 成果物HTMLに含まれる業務情報
- 本人用ダッシュボードとレビュー回答
- CloudFront署名用の秘密鍵
- ペアリング済み端末トークン
- 利用者のAWSアカウントと利用料金

## 想定する脅威

### 悪意ある成果物HTML

AIが生成したHTMLや外部から受け取ったHTMLには、意図しないJavaScriptが含まれる可能性があります。成果物は管理面と別オリジンに置き、管理CookieとレビューAPIから分離します。閲覧面にはサンドボックス付きCSPを適用し、外部通信、フォーム送信、フレーム埋め込み、別画面への遷移を制限します。画像、フォント、音声などはCLIが許可ディレクトリから単一HTMLに埋め込みます。

### 共有URLの流出

共有URLを知る人は有効期限まで閲覧できます。無期限URLは発行せず、利用者が設定した上限を超える期間も拒否します。URLはログ、チャット、画面共有に残ることがあるため、機密性の高い内容には共有URLを使わないでください。`content.retainDays` を設定すると、更新が止まったページは配信先から消え、そのページの共有URLも有効期限を待たずに開けなくなります（[保持期限と保管庫](retention.md)）。

### スマホから送った画像の残留

スクリーンショットには業務情報が写り込むことがあります。一時置き場のバケットは非公開で、配信に使うCloudFrontからは読めません。出し入れは10分で失効する署名付きURLだけで行い、アップロード許可証の条件には`image/jpeg`の形式と1枚15MBの大きさを含めます。PCが取り込んだらその場で削除し、取り込み忘れても7日で消えます（[アーキテクチャ](architecture.md#スマホから画像を渡す)）。

### 秘密鍵の漏えい

秘密鍵はGit管理外とし、ブラウザ、S3、CloudFront Functionには配布しません。漏えい時は鍵ペアをローテーションし、CloudFront Key Groupを更新します。

### ペアリングコードの総当たり

コードは40ビットの暗号学的乱数から生成します。有効期限は10分で、一度だけ利用できます。公開環境で追加の総当たり対策が必要な場合は、利用者の運用規模に合わせてAWS WAFのレート制御を追加してください。

### 意図しないファイルの配信

設定されたルートディレクトリ以外は読み込みません。`realpath`でシンボリックリンクの実体も検査します。ローカル参照は許可された拡張子とサイズのものだけを単一HTMLに埋め込みます。

### AWS費用の悪用

作者が運営する共通基盤はなく、各利用者のAWSにデプロイします。ログ保持期間とDynamoDB TTLを制限しています。公開運用ではAWS Budgetと、必要に応じたLambda同時実行数の上限設定を推奨します。

## 対象外

- 侵害済みの利用者端末またはAWS管理者アカウント
- 共有URLを受け取った正規閲覧者によるスクリーンショットや再配布
- 利用者がCSPを無効化して配信した独自コンテンツ
