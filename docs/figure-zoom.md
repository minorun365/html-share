# 大きな図の全画面表示

全体図やER図のように、本文の幅では文字が読めない図は、そのままの幅で配置し、囲む要素に `data-zoom` を付けます。
閲覧者が図をクリックすると、ブラウザのウィンドウいっぱいに重ねて表示されます。
図の中身は SVG でも画像（`img`）でも同じように拡大表示されます。

```html
<figure data-zoom data-zoom-min="1400">
  <svg viewBox="0 0 2000 1600">…</svg>
  <figcaption>注文・在庫・配送の表の全体図</figcaption>
</figure>
```

| 属性 | 意味 |
|---|---|
| `data-zoom` | クリックで全画面表示にする図の目印。この属性が付いた図があるページにだけ、配信時に処理が埋め込まれます |
| `data-zoom-min` | 全画面で図を表示する最小の幅（px）。ウィンドウがそれより狭いと横にスクロールします。省略するとウィンドウの幅に合わせます |
| `data-zoom-title` | 全画面の上端に表示するタイトル。省略すると SVG の `aria-label` か画像の `alt`、なければ図の説明文を使います |

「閉じる」ボタン、Esc キー、ブラウザの「戻る」のどれでも閉じられます。
ページが同じオリジンの iframe 内で開かれているときは、全画面で表示している間だけ iframe を親ウィンドウいっぱいに広げます。
