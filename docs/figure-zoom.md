# 大きな図の全画面表示

全体図やER図のように、本文の幅では文字が読めない図は、本文の幅のまま置き、囲みに `data-zoom` を付けます。
閲覧者が図をクリックすると、ブラウザの窓いっぱいの重ね画面に図が出ます。

```html
<figure data-zoom data-zoom-min="1400">
  <svg viewBox="0 0 2000 1600">…</svg>
  <figcaption>注文・在庫・配送の表の全体図</figcaption>
</figure>
```

| 属性 | 意味 |
|---|---|
| `data-zoom` | クリックで全画面に出す図の目印。付いた図があるページにだけ、配信時に処理が埋め込まれます |
| `data-zoom-min` | 全画面で図を描く最低の幅（px）。窓がそれより狭いと横にスクロールします。省略すると窓の幅に合わせます |
| `data-zoom-title` | 全画面の上端に出す題。省略すると SVG の `aria-label`、なければ図の説明文を使います |

閉じるのは「閉じる」ボタン、Esc キー、ブラウザの「戻る」のどれでも構いません。
ページが同じオリジンの iframe の中で開かれているときは、開いている間だけ iframe を親の窓いっぱいへ広げます。
